# HAPI Anti-AI-Slop Style Guide v1

## Purpose

This is a working editorial filter for HAPI, Alignment Theory, AGS, AAG, PGDL, website copy, papers, LinkedIn posts, presentations, and marketing. It is not a claim that any single word proves AI authorship. The problem is repetition, clustering, vague polish, and formulaic rhythm.

## Editing rule

1. Hard-ban the expressions in the first two sections from public-facing prose unless a technical reason requires them.
2. Flag the review terms when they repeat, cluster, or substitute for a concrete statement.
3. Preserve HAPI technical vocabulary when it names a real component or defined concept.
4. Prefer a concrete noun, action, test, threshold, example, failure mode, or consequence over an abstract adjective.

## Structure and formatting flags

- **Excessive em dashes:** Use commas, parentheses, periods, or colons unless an em dash is clearly needed.
- **Negation-first parallelism:** Avoid repeated forms such as “not X, but Y” and “not this, not that, just Z.”
- **Three-beat slogan cadence:** Avoid strings such as “fast, safe, and scalable” unless the three items are necessary.
- **Dramatic fragment followed by explanation:** Avoid “The result? …”, “The problem? …”, and “Why? Because …”.
- **Unearned profundity:** Remove phrases such as “something shifted,” “everything changed,” and “let that sink in.”
- **Uniform paragraph rhythm:** Do not make every paragraph the same length or use a repeated claim-explanation-summary pattern.
- **Overformatted sections:** Use fewer headings, fewer bold phrases, fewer colon-heavy labels, and fewer bullet lists.
- **Emoji bullets in professional writing:** Avoid checkmarks, sparkles, arrows, fire icons, and decorative Unicode bullets.
- **Overbalanced hedging:** Do not reflexively present both sides when the evidence supports a direct claim.
- **Repeated summary endings:** Do not restate the same idea at the end of every section.
- **Generic inspirational close:** End with a concrete implication, decision, test, or next action.

## Preferred replacements

| Avoid or review | Prefer |
|---|---|
| `delve into` | examine, analyze, study, describe |
| `underscore` | show, indicate, demonstrate, make clear |
| `pivotal / crucial / vital` | state the concrete consequence instead of adding an importance adjective |
| `landscape` | field, market, system, environment, or the specific domain name |
| `navigate the complexities of` | handle, evaluate, manage, or describe the specific problem |
| `robust` | reliable, tested, fault-tolerant, secure, or the measurable property |
| `seamless` | integrated, low-friction, or describe the actual handoff |
| `transformative` | state what changes, for whom, and by how much |
| `meaningful` | state what authority, choice, action, or outcome changes |
| `amplify` | increase, extend, improve, accelerate, or preserve; keep “agency amplification” only as a defined term |
| `coherence` | consistency, agreement, fit, traceability, or the exact relationship being tested |
| `under pressure` | during failure, under load, during conflict, during time constraints, or under a named condition |
| `load-bearing` | capacity-forming functions, agency-forming functions, necessary, structural, required, or name the dependency |
| `not merely / not just` | state the positive claim directly |

## Copy-paste instruction for future drafting

```text
Write in plain, specific language. Preserve defined HAPI and AGS technical terms, but remove generic AI-polish. Do not use em dashes by default. Do not use negation-first contrasts such as “not X, but Y,” “not merely,” “not just,” or “not only ... but also.” Avoid dramatic fragments, rhetorical questions used as transitions, inspirational conclusions, uniform three-item slogans, and repeated summary paragraphs. Replace abstract adjectives with concrete mechanisms, conditions, examples, tests, or consequences. Flag repeated use of words such as coherence, amplify, convergence, framework, infrastructure, meaningful, pivotal, crucial, underscore, landscape, and transformative. Use direct claims. Vary sentence length naturally. Cut any sentence that only restates the previous sentence.
```

## Scope note

No blacklist can prove whether text was written by AI. Human writers use these expressions too. The editorial goal is to prevent HAPI writing from sounding generic, automated, over-polished, or detached from the actual mechanism being described.
