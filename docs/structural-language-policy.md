# Structural Language Policy

Date: 2026-06-07

`Structural` is not banned. It is useful when it names a concrete arrangement, relation, layer, boundary, or dependency. It becomes weak when it serves as a default synonym for important, deep, recurring, systemic, or serious.

## Working Rule

When reviewing an abstract use, ask:

- What exactly is arranged incorrectly?
- What process fails?
- What boundary matters?
- What rule is being enforced?
- What dependency is created?
- What part of the system is being described?

## Prefer Concrete Mechanisms

Use context-specific terms where accurate:

- execution boundary
- policy boundary
- governance layer
- runtime constraint
- authority failure
- dependency created by the process
- decision rule
- review path
- incentive problem
- workflow failure

Avoid replacing `structural` by default with `architectural`, `foundational`, `systemic`, or `underlying`. Those can be just as vague.

## Acceptable Uses

- "The runtime structure separates objective definition, constraint enforcement, and realignment review."
- "The sitemap entry is a route-structure reference and should be retained."
- "The page title `Shared Core Structure Across Domains` is a title and route surface, not a sentence-level filler use."

## Vague Uses

- "There is a structural problem with oversight."
- "This creates structural pressure."
- "The framework reveals a structural pattern."
- "The structural issue is deeper than behavior."

## Improved Sentence-Level Rewrites

- Vague: "There is a structural problem with human oversight."
  Better: "The reviewer can approve the action, but cannot stop it once execution begins."
- Vague: "The system creates structural dependence."
  Better: "The workflow makes the user rely on the assistant for judgment instead of only for information."
- Vague: "This is a structural constraint."
  Better: "The policy blocks execution until a human confirms authority and scope."
- Vague: "The same structural pattern appears across domains."
  Better: "In each domain, an outside support begins preserving output while the person or institution participates less in the function."
